# Legal Forum

A full-stack discussion forum where people can ask legal questions and get answers from the community. Built with Next.js 14, React, TypeScript, Tailwind CSS, and Supabase.

**Live site:** https://legal-forum-website-complete.vercel.app

## Features

- Email and password authentication with protected routes
- Create and browse discussion threads
- Responsive interface for desktop and mobile
- Supabase Postgres database

## Stack

Next.js · React · TypeScript · Tailwind CSS · Supabase · PostgreSQL

## Run locally

```bash
npm install
npm run dev
```
