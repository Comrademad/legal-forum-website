# Legal Forum

The website for Legal Forum, a Pakistani law firm. It presents the firm's practice areas — criminal, family, corporate, civil, property, and labor law — and gives visitors a way to request a free consultation.

**Live site:** https://legal-forum-website-complete.vercel.app

## What's inside

- Home, About, Services, and Contact pages
- Six practice areas: criminal, family, corporate, civil, property, and labor law
- Free consultation enquiry flow
- Responsive layout with reusable UI components

## Stack

Next.js 15 · React 19 · TypeScript · Tailwind CSS · Radix UI (shadcn/ui) · Framer Motion

## Source

The production source is maintained privately. The live site above is the public demo.
